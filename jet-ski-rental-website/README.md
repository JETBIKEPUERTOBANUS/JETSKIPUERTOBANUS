# Jet Ski Rental Website

Welcome to the Jet Ski Rental Website project! This project is designed to provide a user-friendly platform for renting jet skis. Below you will find information on how to set up and use the website, as well as an overview of its features.

## Table of Contents

- [Features](#features)
- [Setup Instructions](#setup-instructions)
- [Usage](#usage)
- [Contributing](#contributing)
- [License](#license)

## Features

- User-friendly interface for browsing available jet skis
- Responsive design for optimal viewing on all devices
- Interactive elements for a seamless user experience
- Easy navigation to rental information and booking

## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/jet-ski-rental-website.git
   ```

2. Navigate to the project directory:
   ```
   cd jet-ski-rental-website
   ```

3. Open the `index.html` file in your web browser to view the website.

4. For development, you can modify the CSS in `src/assets/css/styles.css` and the JavaScript in `src/assets/js/scripts.js`.

## Usage

- Browse the available jet skis and their specifications.
- Use the booking form to reserve a jet ski for your desired date and time.
- Enjoy a seamless rental experience!
